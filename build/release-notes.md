## Как установить

Если приложение уже стоит, ничего делать не нужно: оно обновится само.

Для новой установки скачайте `Enterload-Setup-1.3.0.exe`. Если Windows покажет «Система Windows
защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: приложение подписано
нашей собственной подписью, а не платным сертификатом.

`Enterload-1.3.0-portable.exe` работает без установки, но обновляться сам не умеет.

## What's new

- **13 languages**: English, Russian, Ukrainian, Belarusian, Kazakh, Uzbek, Azerbaijani, Armenian, Kyrgyz, Tajik, Turkmen, Romanian and Chinese
- The app follows your Windows language and uses English if it isn't on the list
- You can change the language in Settings without a restart
- Errors and the `.txt` file next to the video follow the chosen language too

## Install

If the app is already installed, there's nothing to do: it updates itself.

For a new install, download `Enterload-Setup-1.3.0.exe`. If Windows shows "Windows protected your
PC", click "More info" → "Run anyway": the app carries our own signature, not a paid certificate.

`Enterload-1.3.0-portable.exe` runs without installation but can't update itself.
